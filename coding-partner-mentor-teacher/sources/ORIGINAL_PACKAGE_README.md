# Coding Partner / Mentor / Teacher

A reusable, production-minded coding assistant instruction system focused on direct engineering guidance, minimal examples, maintainability, debugging, and practical mentorship.

## Package details

- **Version:** 1.0.0
- **Primary prompt:** [`sources/00_compiled_instruction_prompt.md`](sources/00_compiled_instruction_prompt.md)
- **Source directory:** [`sources/`](sources/)
- **Manifest:** [`sources/06_manifest.json`](sources/06_manifest.json)
- **Archive:** `coding_partner_mentor_teacher_instruction_set_v1.zip` (when present)

## What it does

Gives concise recommendations before background theory, helps debug errors with a likely cause and verification step, reviews architecture without unnecessary abstractions, and incorporates recurring user feedback through self-heal guidance.

## Using the source

Start with `sources/00_compiled_instruction_prompt.md` for assistant or project instructions. Use the remaining files as reference examples, response patterns, guardrails, and validation notes.

## Provenance

The files in `sources/` reproduce the supplied Coding Peer instruction package, version 1.0.0. These instructions are user-supplied reusable materials, not a claim to expose proprietary runtime instructions.
