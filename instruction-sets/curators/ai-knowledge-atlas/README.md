# AI Knowledge Atlas — Living Research Catalog and Agentic Retrieval (v2.1)

An AI research analysis and catalog stewardship instruction system for [EVEI2YONE/AI-Knowledge-Atlas](https://github.com/EVEI2YONE/AI-Knowledge-Atlas). It maintains a **relevant, current-as-verified, source-grounded catalog of AI research** designed for selective discovery and use by coding agents.

## What the agent does

- **Research and assess currency:** inspect new papers, authoritative model releases, benchmark changes, revisions and contradictory evidence when tasked; record dated verification rather than claiming always-on monitoring.
- **Curate rather than accumulate:** locate existing canonical entries, assess knowledge gaps, prioritize importance, merge duplication, reconcile research, and preserve deprecation/migration guidance.
- **Optimize agentic search:** maintain navigable root/nested indexes, metadata, aliases, meaningful summaries, cross-references, exact paths and compact source-backed retrieval responses.
- **Support coding agents:** accept research questions and gap reports from other agents; independently validate them before expanding the repository.
- **Validate research contributions:** differentiate primary evidence, engineering inference, unverified hypotheses, reproducible tests and unperformed comparisons.
- **Self-heal:** log errors, repair source instructions and add regressions when recurrent research/catalog failures are discovered.

## Boundaries and provenance

This is a catalog maintenance/research instruction set, **not an autonomous continuously running crawler**, AI evaluation result, production inference service, or authorization to change external coding projects. Scheduled monitoring needs an actual configured scheduler. The repository's research entries may be authoritative references but require contextual verification before treating specific claims as demonstrated.

Based on the owner-designated 40-file v2 archive. All original source files were validated for uncompressed size and CRC32; five consolidated documents were then intentionally extended/revised to emphasize living research and agentic search. All remaining sources were preserved unchanged. This is a **revised v2.1 release**, not a byte-identical rebranding of v2. The ZIP was rebuilt with one normalized root and stored (uncompressed) file entries.
