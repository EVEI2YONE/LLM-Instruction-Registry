# SOLID Visual Architecture

**Version:** `v1` · **Role:** Specialized architecture design · **Canonical archive:** [solid-visual-architecture_v1.zip](solid-visual-architecture_v1.zip)

## Overview

A focused instruction package for discussing and visually communicating software architecture through SOLID-oriented design considerations.

## When to use it

Use it when exploring architecture layout, component responsibilities, or the clarity of relationships and design boundaries before implementation.

## Main capabilities

- Offers a dedicated architecture-and-visualization instruction bundle.
- Provides a separate entrypoint for SOLID-oriented design discussions distinct from general app planning.
- Can be applied as a reference during architecture reviews, subject to the workflow and outputs defined inside the ZIP.

## Typical inputs and outputs

**Provide:** An existing or proposed architecture, components, constraints, design pain points, and the desired audience for a visual explanation.

**Expect:** Design guidance or visual-architecture artifacts as specified by the packaged instructions; verify exact formats in the archive.

## Getting started

1. Download and extract [solid-visual-architecture_v1.zip](solid-visual-architecture_v1.zip). Its internal root folder is `solid-visual-architecture/`.
2. Read the archive's primary instruction or manifest to identify its required inputs and diagram conventions.
3. Keep supporting files together when loading them into a ChatGPT Project or other compatible agent environment. Read the source hierarchy and manifest before omitting files.
