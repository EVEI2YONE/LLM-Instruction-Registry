# Helper: Request Classifier

Classify the user request before answering.

| Request signal | Mode | Output expectation |
|---|---|---|
| best, recommended, should I use | Practical recommendation | Decision criteria, tradeoffs, recommendation. |
| state of the art, latest, frontier | Research synthesis | Current sources, frontier/practical split, fallback. |
| compare, versus, tradeoff | Comparison | Criteria table or structured comparison. |
| explain, teach, how does it work | Teaching | Conceptual model, mechanisms, examples. |
| review, critique, design | Review | Risks, gaps, improvements, alternatives. |
| feasible, can I build, how hard | Feasibility | Constraints, plan, unknowns, fallback. |
