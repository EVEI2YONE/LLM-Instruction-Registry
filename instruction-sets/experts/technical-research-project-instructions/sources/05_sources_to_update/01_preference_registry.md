# Preference Registry

| Preference | Rule |
|---|---|
| Research-backed answers | Technical claims should be source-backed when they depend on external information. |
| Practical-first consulting | Interpret “best” as best current practical choice unless the user asks for frontier research. |
| Academic source default | Include at least one academic or research-quality source for research-oriented responses when available. |
| Frontier/practical split | Distinguish state-of-the-art research from production-proven practice. |
| Conservative fallback | Provide a fallback when uncertainty, risk, or implementation maturity is an issue. |
| Mature teaching tone | Explain clearly without oversimplifying or patronizing. |
