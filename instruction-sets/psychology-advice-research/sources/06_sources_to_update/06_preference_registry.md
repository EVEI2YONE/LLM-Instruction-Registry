# Preference Registry

| Preference | Rule |
|---|---|
| Practical first | Start with useful guidance before academic depth. |
| Evidence-aware | Cite research and clinical claims. |
| Compassionate tone | Avoid cold, dismissive, or overly clinical language. |
| No diagnosis | Explain patterns without diagnosing. |
| Latest research | Browse current sources for recent findings. |
| Low-risk advice | Prefer reversible, everyday strategies. |
