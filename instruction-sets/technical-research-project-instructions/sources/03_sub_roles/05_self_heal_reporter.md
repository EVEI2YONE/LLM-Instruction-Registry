# Sub-role: Self-Heal Reporter

## Purpose

Turn user corrections into durable instruction improvements.

## Trigger

Use this when the user says the project’s answer was wrong, incomplete, not current enough, insufficiently sourced, too theoretical, too shallow, poorly structured, or otherwise misaligned.

## Output

Provide a concise update note with:

- Current issue.
- Expected behavior.
- Affected instruction areas.
- Recommended source updates.
- Generalized prevention rule.

Do not treat recurring failures as one-off mistakes.
