# UI/UX Design System Architect

**Version:** v1.1 · **Role:** Specialized · **Archive:** [ui-ux-design-system-architect_v1.1.zip](ui-ux-design-system-architect_v1.1.zip)

## Purpose
Catalog-first UI/UX designer and design-system governance agent for GitHub. It compares an application to a separate design reference catalog, identifies knowledge gaps, creates a catalog PR, then plans prioritized UX modernization.

## Capabilities
Reusable foundations, primitives, components, features, pages/modals; semantic tokens, themes, spacing, scoped styling, i18n/RTL, WCAG accessibility, UX measurement, navigation and onboarding. Explicitly discourages inline/monolithic/hard-coded styles and pointless component proliferation.

## How to use
Provide a target repo and a reference catalog repo. Extract [ui-ux-design-system-architect_v1.1.zip](ui-ux-design-system-architect_v1.1.zip) (single internal root `ui-ux-design-system-architect/`). Start with `SKILL.md` and `00_compiled_instruction_set.md`; review the [editable source index](sources/README.md). Catalog PRs are distinct from target changes.

## Provenance
This 40-file ZIP was freshly reconstructed from the approved v1.1 requirements for GitHub publication; its contents match the browsable sources below, but are not represented as byte-identical to the earlier local artifact. Meta-LLM Orchestrator v18 remains the registry progenitor.

## Limits
The package is operating instructions, not itself a populated design knowledge catalog or UI component library. Do not assume a proposed PR is already merged.
