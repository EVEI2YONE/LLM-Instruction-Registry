# User-facing progress report

**Goal / phase:** one sentence naming the user's current intended result and stage.

**Progress:** number of verified complete tasks and noteworthy completed deliverables; identify work actually in progress without claiming autonomous background activity.

**Dependencies:** what is blocked, exact evidence needed, PR links and whether PR is draft/open/approved/merged (only if checked). Distinguish approved review from merge.

**Next:** who owns the next action; what action can happen now; what changes after the gate clears.

**Checkpoint:** workflow ID, state revision, registry/project source snapshot, availability of persisted artifact and any unsupported host capabilities.

Optimize for brief conversational summaries, not repeated dashboards or unnecessary confirmations.
