# Generic or unknown target

When runtime capability is unknown, create a portable entrypoint, addressable sections, a manifest, optional target adapter notes and generated upload/prompt bundles only as needed.

Preserve pinned sources, catalog references, common-rule status, human-approval limits, and shared context/artifact contracts. Do not invent native filenames, tool calls or subagent execution. Mark unknown features and integration tests NOT_RUN.

Describe installation requirements and provide an explicit fallback for offline, no-files or prompt-only environments.
