# Local Claude Code-style agent

Default to least-privileged read-only discovery; do not escalate shell, network or file permissions through lookup instructions. Verify actual client version, native instruction entrypoints, supported skill/subagent tools, permission grants, source checkout and context persistence. Generate CLAUDE.md or native skills only if supported by the target, with scoped tools and no secretly broadened permissions.

Use selected registry instructions via section lookup; never load every package. Child agents must be spawned through a demonstrated native API or an authorized local runner with explicit run/task/context scopes. Store cross-agent artifacts by versioned reference, not implicit common memory.

Validate installation and actual agent invocation separately. When no native spawning exists, provide a truthful single-agent fallback.
