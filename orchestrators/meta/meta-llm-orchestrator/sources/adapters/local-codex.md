# Local Codex-style agent

Verify installed client/version, actual repository instructions, skill loader, tools, shell/network permissions, native subagent API, local SDK/process adapter and project authority.

Use pinned registry checkout with selectively loaded SKILL.md and manifest-indexed sections. Generate AGENTS.md or local skill material only if the runtime supports it. Dynamic delegation requires configured, verified tools/SDK/process execution; mere role documentation is not a running agent. Pass bounded task/context/artifact references and enforce user/owner approvals.

If tools are unavailable, generate portable local instructions and an explicit integration plan. Report tests not run rather than assuming execution.
