# Scenario calibration — optional examples

Example A: "Make a PR reviewer for my local coding agent." Search registry first; reuse `pragmatic-pr-reviewer` when fit, probe the installed local agent, generate only target-native packaging and scoped permissions. Don't create a second PR reviewer unnecessarily.

Example B: "Make a hosted chatbot that can dynamically consult specialists." Verify the hosted site exposes native child creation or a registered tool to the authenticated gateway. Generate task/context/artifact contracts, external-service setup and a single-agent fallback. A GitHub link is not an invocation interface.

Example C: "Upgrade all 49 packages to lookup-first." First release and validate the generator; then migrate all registered packages under a separate explicit scope. Use one versioned source release per package, preserve old ZIPs and evaluate retrieval quality for every package, not just a small pilot.

Example D: "Fix a mistaken approval behavior." Identify the actual governing policy, record evidence, block consequential actions during governance ambiguity, and propose a reviewed policy decision plus regression test. Never grant an agent the right to approve its own release.
