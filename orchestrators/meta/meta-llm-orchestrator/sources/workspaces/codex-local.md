# Local Codex-style agent adapter

Verify repository root, git remotes, working tree, sandbox, tool availability, local tests and current rules. Choose the repository instruction convention supported by the installed Codex environment (potentially AGENTS.md) rather than blindly creating it. Generate scoped tasks, file ownership, completion/test commands and PR policy. Never assume push permission, unrestricted shell or secret access; honor user approvals for destructive edits and external writes. Keep reusable skill modules separate from app source.
