# Online deployed chatbot adapter

Check hosting/provider model and system/developer message interfaces; actual tool schemas and identity boundaries; API connectors; tenant isolation; state persistence; logging, observability, consent and escalation routing. Generate platform-neutral core instructions plus a verified deployment configuration and tool contract. A chatbot that cannot call tools can **advise** but cannot truthfully claim PR creation, file writes, automated research or deployments. Supply explicit backend actions only when authenticated and authorized.
