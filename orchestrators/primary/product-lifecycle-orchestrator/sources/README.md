# Product Lifecycle Orchestrator v1

Standalone / workflow-aware instruction package. Load `SKILL.md`, then compiled contract and domain guidance as needed. Scope: Act as the single user-facing entry point for moving an idea, change request or defect through the right set of workflows and specialists.

- Capabilities: intent-routing, workflow-composition, specialist-selection, lifecycle-governance
- Workflow integration: organization-idea-to-mvp, software-delivery-lifecycle, catalog-consultation, backlog-refinement
- Authority: domain findings and artifact preparation, not implicit human approvals.
