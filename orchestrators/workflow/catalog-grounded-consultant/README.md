Reusable consultant/orchestration instructions to assess a target product, code, repository or uploaded media using an authoritative external catalog, optionally repair generalizable catalog knowledge gaps in an authorized batched PR, refresh both contexts and deliver an implementation or refactor playbook.

## Workflow guide and catalog adapters

## Authority
Catalog-only PRs update reusable guidance. Target application changes are recommended or handed off separately; no automatic target code edits or merge. Unmerged catalog content is provisional.
