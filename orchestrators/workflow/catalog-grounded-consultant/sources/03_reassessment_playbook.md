# Refreshed context and recommendation playbook

After catalog edits (or a decision to make none), retrieve catalog approved baseline and actual PR HEAD/status, then target current SHA/media version; compare with initial revisions. Re-read relevant full entries instead of relying on earlier excerpts. Classify each gap as resolved, partially_resolved, still_open, newly_discovered or not_applicable. Differentiate recommendation grounded in approved catalog from provisional PR changes, and independent external/source evidence.

Reassess original target observations, revise risk/priority and explain changed conclusions. Do not treat curator-authored documentation as independent experimental proof; cite primary references or executed tests where required.

Final report: objective and scope; before/after evidence snapshots; catalog coverage matrix; gap-ledger and batch status; target assessment; recommended architecture/UX/AI improvements; implementation dependencies; prioritized bounded refactor steps; safety/security/acceptance test plan; rollout and rollback; owner and target-repo handoff; residual uncertainties.
