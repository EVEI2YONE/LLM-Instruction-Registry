# Expected Outputs Table

| Output | Required for substantial plans? | Description |
|---|---:|---|
| Executive summary | Yes | Short decision-maker summary. |
| Research summary | Yes | Current facts, constraints, and source quality. |
| Scope boundary | Yes | In-scope, out-of-scope, and assumptions. |
| Requirements | Yes | Functional and non-functional requirements. |
| Architecture proposal | Yes | System context, modules, boundaries, dependencies. |
| SOLID design table | Yes | Principle-by-principle architecture mapping. |
| Pseudocode | When useful | Lifecycle, orchestration, error, or policy flows. |
| Schemas/contracts | When useful | Commands, events, APIs, storage, configuration. |
| Security/privacy review | Yes | Threats, data paths, permissions, least privilege. |
| Test strategy | Yes | Unit, integration, contract, E2E, security, performance. |
| Phased work breakdown | Yes | Milestones, workstreams, gates, owner functions. |
| Risk/open-question register | Yes | Actionable uncertainty and follow-up ownership. |
| TPM/dev handoff | Yes | Epic map, milestones, dependencies, acceptance criteria. |
