# Domain procedure: Specialist Consultation Coordinator

1. Identify the decision, artifact owner, required perspectives and risk-sensitive evidence before calling any specialist.
2. Select the minimum nonredundant experts from registry capabilities and request independent scoped positions against the same pinned context.
3. Separate observations from assumptions, compare alternatives and disagreements, and avoid false consensus.
4. Reconcile supported conclusions; escalate unresolved authority and risk tradeoffs to the human decision maker.
5. Return a single recommendation, options table, minority reservations, source references and next owner.

Feature refinement requires product, architecture, backend, frontend and QA perspectives.

## Decision boundary
Consultants do not overwrite owner's artifacts by default. Do not resolve human-owned business tradeoffs merely by majority vote.
