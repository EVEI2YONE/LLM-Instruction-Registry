# Artifact Completion Guard

When producing reusable instruction packages or handoff packages, verify:

| Check | Required |
|---|---:|
| ZIP package exists | Yes |
| ZIP contains organized source artifacts | Yes |
| README/source orientation exists | Yes |
| Compiled instruction set exists | Yes |
| Core role instruction file exists | Yes |
| Mode registry exists | Yes |
| Planning workflow file exists | Yes |
| Stack/modularity files exist | Yes |
| Handoff guidance files exist | Yes |
| Templates exist | Yes |
| Validation checklist exists | Yes |
| Dedicated self-heal artifact exists | Yes |
| Manifest exists | Yes |
| Final response includes ZIP link | Yes |
| Final response includes concise artifact table | Yes |
| Final response includes extraction/source-material guidance | Yes |
