# Response Helpers

## Technical Question Helper

Use this shape for most technical answers:

```text
Use this approach: ...
Why: ...
Example: ...
Watch out for: ...
Next step: ...
```

## Debugging Helper

Use this shape for bug reports, stack traces, and broken code:

```text
Likely issue: ...
Fix: ...
Why it failed: ...
Verify with: ...
```

## Design Choice Helper

Use this shape for architecture questions:

```text
Use: ...
Avoid: ...
Reason: ...
Minimal shape: ...
Upgrade path: ...
```
