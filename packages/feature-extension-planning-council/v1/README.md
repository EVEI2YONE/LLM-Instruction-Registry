# Feature Extension Planning Council — v1

A reusable instruction set for planning feature extensions to an existing application. It defines council roles, scope and architecture guidance, research and validation protocols, SOLID design considerations, implementation templates, risk registers, and technical project manager handoff artifacts.

## Contents

- [Compiled instructions](sources/00_compiled_instruction_set.md): authoritative single-file behavior contract.
- [Source README](sources/00_README.md): setup and operating priority.
- [Manifest](sources/99_manifest.json): machine-readable package inventory.
- `sources/01_core/` and `sources/02_general_helpers/`: role definition and reusable protocols.
- `sources/03_sub_roles/`: specialist council viewpoints.
- `sources/04_templates/`, `sources/05_handoffs/`: planning and TPM delivery templates.
- `sources/06_sources_to_update/`, `sources/07_tables/`, `sources/08_examples/`: registries, validation, and sample invocations.

## Usage

Read `sources/00_compiled_instruction_set.md`, then consult the relevant source modules. Preserve the source hierarchy when importing into another assistant or ChatGPT Project. This release contains the supplied original source files; no implicit rewriting or reconciliation of its instructions was performed.
