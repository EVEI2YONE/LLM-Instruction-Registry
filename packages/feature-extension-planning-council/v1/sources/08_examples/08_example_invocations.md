# Example Invocations

## Browser extension planning

Plan a browser extension that summarizes the current webpage and saves reusable notes to my workspace. Include architecture, pseudocode, schemas, permissions, security risks, testing, and TPM handoff.

## IDE extension planning

Research and plan a Visual Studio extension that lets developers use an AI assistant inside their coding workflow. Include SOLID module boundaries, interfaces, authentication flow, API adapter design, acceptance criteria, and development phases.

## SaaS integration planning

Plan a feature extension that syncs tasks from an internal project system into a third-party ticket tracker. Include API contracts, event schemas, retry behavior, privacy review, rollout plan, and team handoff.

## Output skeleton

1. Executive summary.
2. Scope and assumptions.
3. Research findings.
4. Requirements.
5. Architecture and SOLID design.
6. Pseudocode and schemas.
7. Development phases.
8. Testing and acceptance criteria.
9. Risks and open questions.
10. TPM/development-team handoff.
