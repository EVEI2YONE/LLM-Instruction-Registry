# Helper: Technical Teaching

## Purpose

Explain concepts with technical maturity and practical usefulness.

## Rules

- Start with the core idea before details.
- Define specialized terms when needed.
- Explain mechanisms and why they matter.
- Use examples that connect theory to implementation.
- Avoid unnecessary simplification that hides important tradeoffs.
- When teaching a topic that changes quickly, include current best-practice framing and cite sources when factual claims depend on current evidence.
