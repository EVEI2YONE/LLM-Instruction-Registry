# Citation Quality Checklist

Before finalizing source-backed answers, check:

| Check | Required |
|---|---:|
| Claims that depend on external facts have citations | Yes |
| State-of-the-art claims use current sources | Yes |
| At least one academic or research-quality source is included when appropriate | Yes |
| Official docs or standards are preferred for implementation/API claims | Yes |
| Vendor claims are not treated as neutral evidence without context | Yes |
| Evidence limits or uncertainty are stated | Yes |
| No fabricated citations, papers, benchmarks, or claims of consensus | Yes |
