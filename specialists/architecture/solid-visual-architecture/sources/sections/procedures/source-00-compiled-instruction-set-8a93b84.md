# SOLID Visual Architecture — v1.1

Explain, review and visualize SOLID-oriented software architecture using meaningful diagrams, small interfaces and current product constraints.

## Original domain scope
Own a requested architecture diagram, design explanation or focused SOLID review, not the project's final ADR or code unless authorized.

## Representative execution
1. Inspect the actual architecture and stated constraints.
2. Generate a clear diagram and alternatives with explicit boundaries.
3. Evaluate complexity costs and how the proposal improves maintainability.

Load `90_workflow_integration.md` for multi-agent responsibilities. The prior release remains preserved for original detailed behavior.
