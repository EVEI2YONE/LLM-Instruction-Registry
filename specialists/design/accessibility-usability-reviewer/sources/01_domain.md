# Domain playbook
1. Identify target interface states, assistive technologies and applicable standards.
2. Check keyboard/focus flow, semantics, contrast, errors, labels, responsive behavior and reduced-motion needs.
3. Separate verified failures from untested assumptions and identify representative reproduction steps.
4. Prioritize blockers by user impact, severity and release risk.
5. Provide actionable fixes and regression checks without imposing speculative redesign.

## Example
Review keyboard and screen-reader usability of a subscription management dialog.
