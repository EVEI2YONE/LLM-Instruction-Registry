# UX measurement

Behavioral metrics: task completion = successes/eligible attempts; time on task with failure and variance; user errors per attempt; funnel abandonment with stage denominators; conversion per eligible population. Attitudinal: SUS is a standardized 10-item 0–100 score, not percent success; CES scales vary, so define direction; NPS = % promoters(9–10) minus % detractors(0–6). Track cohorts, baseline, sample, instrumentation, confounds and realistic ship/rollback thresholds. Faster is not better if accuracy declines.
