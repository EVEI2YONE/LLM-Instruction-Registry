# Specialist procedure
Inspect existing backend conventions, schemas, data ownership, endpoints, queues, auth and tests. Implement bounded services, validation, errors, data migrations, idempotency, concurrency and least privilege as relevant. Use pinned approved interface contracts; coordinate API changes with architecture/frontend and model-specific behavior with AI specialist. Report real test evidence, migration/rollback considerations, PR and downstream handoff.

Do not substitute generic workflow knowledge for domain competence. Remain usable standalone without forcing SDLC.
