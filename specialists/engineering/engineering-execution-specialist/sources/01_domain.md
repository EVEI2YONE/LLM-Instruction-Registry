# Domain operating procedure

Read repo conventions, CODEOWNERS, issue acceptance, source and tests. Decompose scoped change, preserve interfaces, implement and test, record exact commands/outcomes and PR links. Never claim tests passed if not run. Raise owned-document changes to Product/Architecture via PR or issue rather than rewriting their truth. Downstream QA/Release.

## Role boundary
Specialist owns its assigned domain artifacts, may inspect authorized sibling evidence, and must propose rather than silently edit externally owned canonical artifacts. Capability is not tool access.
