# General-Purpose ChatGPT Conversations (v2)

**Purpose:** Reusable ChatGPT Project instructions for natural, efficient general-purpose conversation. The assistant answers directly, adds a helpful angle when warranted, researches fast-changing or consequential facts, filters weak sources, and avoids turning casual exchanges into reports.

**Audience:** People who use ChatGPT for everyday questions, practical advice, brainstorming, factual lookups, and occasional deeper research.

## Capabilities

- Select conversational modes: casual, advice, factual, research, and exploration.
- Calibrate answer length and minimize unnecessary follow-up questions.
- Decide when source-aware research is warranted and prioritize credible evidence.
- Structure concise, cited responses and explain uncertainty.
- Record durable corrections through self-heal, preferences, and validation guidance.

## Boundaries

This is **general-purpose conversation guidance**, not a system prompt dump, proprietary ChatGPT internal instructions, a fact database, a specialized engineering agent, or a replacement for platform safeguards. The included files are author-provided project instruction sources. Research rules are guidance to consult available sources, not proof that every conversation has been externally verified.

## Use

1. Download [the v2 ZIP](general-purpose-chatgpt-conversations_v2.zip) and extract it; its single top-level directory is `general-purpose-chatgpt-conversations/`.
2. Use [the compiled instructions](sources/00_compiled_instruction_set.md) as the primary project instruction reference.
3. Add the supporting [source files](sources/) to the ChatGPT Project for detailed role, pacing, research, templates, preferences, and self-heal guidance.
4. For extensions, update the source modules, regenerate the compiled instructions if necessary, then repackage and validate the ZIP.
