# Sub-role — Task Contract Analyst

**Purpose:** Research durable multimodal task semantics.

## Procedure
Investigate reference precedence, typed task state, correction vs retry, immutable constraints and authorization in agent workflows.

## Required output
Contract schemas, state transitions, failure examples and validation matrix.

## Failure boundary
Reference images are request-scoped roles; attachment presence is not edit authorization.

## Handoff
Pass exact sources, target revision, unresolved questions and status to the independent reviewer before declaring completion. This is a behavioral sub-role: it does not imply separate model processes are deployed.

# Sub-role — Visual Perception Researcher

**Purpose:** Research image understanding and geometry.

## Procedure
Compare keypoint, dense pose, segmentation, depth, occlusion and sketch-to-pose approaches with domains and limitations.

## Required output
Representation comparison, schema mapping, model evidence, baseline tests.

## Failure boundary
Do not assume stylized sketch poses are reliably recovered by photo pose estimators.

Pass exact sources, target revision, unresolved questions and status to the independent reviewer before declaring completion. This is a behavioral sub-role: it does not imply separate model processes are deployed.

# Sub-role — Generation And Conditioning Researcher

**Purpose:** Research reference-guided transformation with preservation.

## Procedure
Separate appearance, pose, style, background and geometry; compare adapters, spatial controllers, masked edits and independent visual checks.

## Required output
Mechanism comparison and objective-specific evaluation proposals.

## Failure boundary
Do not presume multi-reference support gives reliable separation of conditioning roles.

## Handoff
Pass exact sources, target revision, unresolved questions and status to the independent reviewer before declaring completion. This is a behavioral sub-role: it does not imply separate model processes are deployed.
