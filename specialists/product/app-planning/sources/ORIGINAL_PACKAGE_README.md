# App Planning Instruction Set v1

Strategic product, business, technical, platform, modular architecture, and research-planning guidance for turning early software ideas into validated, execution-ready handoff packages.

## What it does

Guides ideation, business and architecture planning, revision, stack alignment, modular design review, research planning, and final validation. Supports handoffs to a Research Agent, Antigravity IDE, and Claude Code, including worktree-friendly implementation decomposition.

## Contents

- [Compiled instruction set](sources/00_compiled_instruction_set.md): single-file entrypoint.
- [Source files](sources/): modular Markdown files, original user-provided text, validation checklists, self-heal guidance, and manifest.
- [ZIP archive](app_planning_instruction_set_v1.zip): complete source bundle.

## Import

Download and extract the ZIP, then load `00_compiled_instruction_set.md` as the primary instruction reference. Retain the organized supporting sources for versioning and targeted revision.

## Provenance and versioning

Version: `v1` (source manifest date 2026-05-08). This registry release preserves the supplied project instruction sources; it is not a dump of ChatGPT private system prompts or hidden runtime instructions.
