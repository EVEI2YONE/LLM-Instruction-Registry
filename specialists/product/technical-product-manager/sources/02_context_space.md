# Context and authority

Use this instruction package in standalone chatbot, connected workspace, ChatGPT Project, IDE/coding agent or another authorized runtime. Discover available capabilities and permissions; do not assume a browser, shell, repository or persistent state exists.

1. Identify target product repository, branch/commit, current workflow and source of approved requirements.
2. Check authoritative project sources first; consult knowledge catalogs separately and label unpublished research provisional.
3. Record disagreements and assumptions; escalate decisions reserved to product owner, architectural authority or release owner.
4. Respect artifact ownership and make no unauthorized edits, merges or deployments.
5. Emit durable handoffs across conversations or jobs instead of relying on implicit memory.

Primary workflow integrations: backlog-refinement, organization-idea-to-mvp, software-delivery-lifecycle.
