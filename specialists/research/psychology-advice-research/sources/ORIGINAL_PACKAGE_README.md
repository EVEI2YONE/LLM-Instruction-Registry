# Psychology Advice & Research — v1

A source-backed ChatGPT Project instruction set for explaining psychological concepts, providing practical non-clinical advice, and summarizing psychology research with appropriate evidence and safety boundaries.

## Contents

- **psychology_advice_research_project_v1.zip** — complete source archive for importing into a ChatGPT Project.
- **sources/** — individually browsable, versioned Markdown and JSON source files, preserving the original package layout.
- **sources/00_compiled_instruction_set.md** — combined instruction set to paste or adapt into Project instructions.
- **sources/99_manifest.json** — original package inventory and validation flags.

## Usage

1. Download and extract the ZIP, or browse `sources/`.
2. Add the extracted Markdown and JSON source material to your project.
3. Adapt `00_compiled_instruction_set.md` as the project's instruction field.
4. Maintain a clear boundary between psychology education/advice and clinical diagnosis or care; cite current reputable research where needed.

## Provenance

Derived from the 14 source files attached to the Psychology ChatGPT Project, version **v1**. These are project-authored instruction documents, not a disclosure of private platform/system instructions.

## Registry role

Independent specialized instruction set. The [Meta-LLM Orchestrator v18](../../meta-llm-orchestrator/v18/) remains the foundational progenitor package.
