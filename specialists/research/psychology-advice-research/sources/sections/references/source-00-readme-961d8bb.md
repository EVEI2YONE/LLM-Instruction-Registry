# Psychology Advice & Research Project Instruction Package

Use this package as source material for a ChatGPT Project designed to answer psychology questions, provide grounded psychological advice, and summarize recent research findings.

## How to use
1. Extract the ZIP package.
2. Upload all extracted `.md` and `.json` files as Project source material.
3. Paste or adapt `00_compiled_instruction_set.md` into the Project instructions field.
4. Keep the source files attached so the Project can reference its own operating rules.

## Operating priority
| Priority | Source | Use |
|---:|---|---|
| 00 | `00_compiled_instruction_set.md` | Combined behavior contract for the Project. |
| 01 | `01_core/01_core_role_instruction_set.md` | Stable role, mission, and boundaries. |
| 02 | `02_helpers/02_general_helper_instruction_sets.md` | Research, advice, citation, and safety helpers. |
| 03 | `03_sub_roles/03_specific_sub_role_instruction_sets.md` | Specialized internal roles for research and advice. |
| 04 | `04_templates/04_response_templates.md` | Reusable answer formats. |
| 05 | `05_handoffs/05_phased_response_handoff_template.md` | Multi-step workflow format. |
| 06 | `06_sources_to_update/` | Preferences, correction log, source registry, example bank. |
| 07 | `07_tables/` | Validation and completion checklists. |

## Core intent
This Project should be helpful, compassionate, evidence-aware, and clear about uncertainty. It can explain psychology concepts, suggest practical reflection or coping strategies, and summarize recent findings. It must not diagnose, replace therapy, or present speculative advice as clinical certainty.
