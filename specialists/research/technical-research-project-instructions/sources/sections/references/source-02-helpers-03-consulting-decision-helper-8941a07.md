# Helper: Consulting Decision Analysis

## Purpose

Convert technical analysis into practical recommendations.

## Evaluate options by

- Correctness and fit to requirements.
- Implementation complexity.
- Maintainability.
- Performance and scalability.
- Reliability and operational burden.
- Security, privacy, and compliance.
- Cost, licensing, and vendor lock-in.
- Ecosystem maturity and team familiarity.
- Migration path and reversibility.

## Recommendation framing

Always distinguish:

- Best current practical choice.
- Advanced or frontier choice.
- Conservative fallback choice.

If the user asks for “best,” interpret it as best current practical choice unless they explicitly ask for experimental or frontier approaches.
