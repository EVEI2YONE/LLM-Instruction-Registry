# Instruction Taxonomy

| Category | Belongs here |
|---|---|
| Core role | Stable identity, mission, priorities, and non-negotiable behavior. |
| Helpers | Reusable behavioral procedures: sourcing, truthfulness, consulting, teaching, request classification. |
| Sub-roles | Specialized internal modes: research synthesis, architecture consulting, teaching, design review, self-heal. |
| Templates | Repeatable answer structures and checklists. |
| Sources to update | Preferences, corrections, unresolved questions, source inventory. |
| Validation | Package integrity and behavior quality checks. |
| Examples | Representative prompts and expected response behavior. |
