# Instruction and workflow templates

Use the [workflow schema](../schemas/workflow.schema.json), [workspace capability schema](../schemas/workspace-target.schema.json), [handoff schema](../governance/handoff.schema.json) and [capability ownership schema](../governance/capability-ownership/capability-ownership.schema.json). New specialist instructions should inherit a portable core and generate a native workspace wrapper only when the target supports it. Publish real ZIPs and browsable sources together, retain prior versions, and validate manifests.
