# UI/UX Design System consultation adapter

## Existing specialist and catalog scope
Use `instruction-sets/curators/ui-ux-design-system-architect/` (v1.1 as currently registered) as the **curator/UX assessor**. Its instructions explicitly define target product + shared design catalog, catalog-first knowledge audit and separate target remediation:
- `sources/00_compiled_instruction_set.md`: two-repo model and target/canonical catalog separation.
- `sources/02_helpers/10_catalog_first_knowledge_audit.md`: coverage and existing-entry triage.
- `sources/04_templates/08_migration_gap_report.md`: recommended final report and priority matrix.

## Intake and routing
Appropriate for uploaded screenshots, product URLs, design assets, user journey screenshots, frontend code or repo and design catalog. Inspect actual content and describe what cannot be verified from static images (keyboard interactions, behavior, analytics, business outcomes). Use existing design system, UI tokens/components/patterns and accessibility evidence. Do not copy proprietary screenshots into a public catalog without authorization.

## Curation and reassessment
Catalog-first missing standards/design knowledge => propose canonical catalog updates through a reviewable catalog PR before preparing target migration recommendations. Keep PR guidance provisional until approved. Refresh target screenshots/route/component code and catalog entries at updated revisions. Produce structured UX assessment, target gap report, priority/dependency matrix, test/measurement plan and actionable Frontend/UI-UX handoff. No unauthorized target implementation.
