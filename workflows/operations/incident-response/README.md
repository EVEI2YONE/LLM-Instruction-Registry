# incident-response

Triage, contain and remediate production incidents with verified timelines and minimal risk.

The coordinator is `software-delivery-lifecycle` when its published capabilities match the task; the primary orchestrator may execute simple plans directly. Human approval applies at explicit gates. Product artifacts remain in authoritative project repositories.
