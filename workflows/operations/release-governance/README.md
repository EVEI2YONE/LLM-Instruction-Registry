# release-governance

Prepare production change decisions, rollback and post-release checks.

The coordinator is `release-governance-coordinator` when its published capabilities match the task; the primary orchestrator may execute simple plans directly. Human approval applies at explicit gates. Product artifacts remain in authoritative project repositories.
