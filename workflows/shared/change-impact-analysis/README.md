# change-impact-analysis

Analyze how a proposed change propagates across product, interfaces, resources, code, tests and release.

The coordinator is `product-lifecycle-orchestrator` when its published capabilities match the task; the primary orchestrator may execute simple plans directly. Human approval applies at explicit gates. Product artifacts remain in authoritative project repositories.
