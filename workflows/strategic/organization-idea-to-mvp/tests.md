# Workflow acceptance scenarios

1. Existing strategy/PRD reused, not duplicated.
2. Missing investment approval blocks MVP commitment, but not safe discovery.
3. AI hypothesis triggers non-AI baseline and measurable eval.
4. Backend contract changes force affected frontend handoff revalidation.
5. Passing CI does not prove MVP business learning.
6. SDLC and organization workflow reuse the same artifacts, no competing records.
